# SAMENI VPN — نسخه Ultimate با تنظیمات کامل و بهینه‌سازی اتصال

## قابلیت‌ها
- موتور Xray از طریق `flutter_v2ray 2.0.0` (Android).
- اتصال و قطع اتصال VPN، نمایش وضعیت، مصرف داده و سنجش تأخیر اتصال جاری.
- مدیریت سرورها و پشتیبانی ورودی لینک‌های `vmess://`، `vless://`، `trojan://` و `ss://`.
- دریافت اشتراک فقط از HTTPS، حذف تکراری‌ها، سقف ۲۰۰ سرور کشف‌شده و تست مرحله‌ای.
- DNS مستقل، فعال/غیرفعال‌سازی، تیک اعمال خودکار، اعمال فوری با راه‌اندازی دوباره تونل، و DNS دلخواه.
- Splash ورودی با حلقه نورانی متحرک، حرکت نرم تب‌ها، افکت ورود مرحله‌ای کارت‌های تنظیمات، انیمیشن اتصال/قطع و خروج با کلید برگشت؛ خاموش‌کردن انیمیشن‌ها نیز از تنظیمات ممکن است.
- تصویر هخامنشی در صفحه شروع، خانه و آیکن لانچر معمولی/گرد اندروید.
- تب تنظیمات کامل با کنترل انیمیشن، بازخورد لرزشی، نمایش آمار ترافیک، مدیریت منابع اشتراک و ابزارهای عیب‌یابی. دکمه بهینه‌سازی مسیر، تا ۳۱ سرور را با Xray آزمایش و سرور کم‌تأخیرتر را برمی‌گزیند؛ این قابلیت سرعت پایه اینترنت اپراتور را افزایش نمی‌دهد.
- خطایابی شروع موتور Xray و دکمه تلاش مجدد به‌جای گیرکردن بی‌نهایت روی لودینگ.
- مهلت زمانی برای مجوز/شروع/قطع تونل، جلوگیری از کلیک و تست تکراری، و جلوگیری از حذف/تعویض سرور فعال.
- محدودکردن هم‌زمانی تست‌ها برای کاهش فشار روی گوشی، ردکردن منبع اشتراک HTTP و جلوگیری از تغییر مسیر HTTPS به HTTP.
- هشدار برای خطای ذخیره‌سازی محلی، سقف منابع و DNSهای سفارشی، و پاک‌سازی پینگ سرور حذف‌شده.


## ساخت APK در ویندوز
1. Flutter SDK و Android SDK را نصب و `flutter doctor` را بدون خطای ضروری اجرا کنید.
2. قبل از بازکردن پروژه در Android Studio، یک‌بار `prepare_android.ps1` را اجرا کنید تا Gradle Wrapper استاندارد Flutter ساخته و آیکن‌ها اعمال شوند.
3. سپس پروژه را در Android Studio باز کنید یا `build_apk.bat` را اجرا کنید.
4. خروجی: `build\app\outputs\flutter-apk\app-release.apk`

## ساخت با GitHub Actions
فقط Workflow به‌روز `.github/workflows/build.yml` با هر Push روی شاخه `main` اجرا می‌شود تا دو ساخت تکراری ایجاد نشود. فایل APK از بخش Artifacts دریافت می‌شود.

## محدودیت‌ها و نکات امنیتی
- کانفیگ‌های عمومی متعلق به افراد ناشناس‌اند؛ پایداری، سرعت، حریم خصوصی یا امنیت آن‌ها تضمین نمی‌شود. برای حساب‌های مالی یا اطلاعات حساس از سرور عمومی ناشناس استفاده نکنید.
- تست تأخیر Xray به‌ترتیب از Cloudflare، Google و Gstatic Generate 204 استفاده می‌کند؛ این تست اتصال لحظه‌ای است و تضمین سرعت پایدار یا دسترسی همه اپراتورها نیست.
- پروتکل‌های UI فعلی: VMess، VLESS، Trojan و Shadowsocks. Hysteria2/TUIC در این نسخه پشتیبانی نشده‌اند.
- DNS انتخابی در تنظیمات Xray داخل تونل اعمال می‌شود، نه DNS سراسری Android.
- هنگام خروج، برنامه تونل را عمداً قطع نمی‌کند؛ وضعیت سرویس VPN تابع موتور بومی و Android است.
- برای انتشار عمومی، سیاست حریم خصوصی، امضای release با keystore خصوصی، مجوز/اعلام foreground service و سازگاری ۱۶KB native libraries را جداگانه بررسی کنید.

## اعتبارسنجی
ساختار Dart، اسکریپت‌های آماده‌سازی Android، YAML مربوط به GitHub Actions و XML مانیفست بازبینی ایستا شده‌اند. این محیط Flutter/Android SDK ندارد؛ بنابراین APK این نسخه در اینجا کامپایل یا روی گوشی واقعی آزمایش نشده است. اولین Run در GitHub Actions باید به‌عنوان build validation استفاده شود.
